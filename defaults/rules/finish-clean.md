Look over what you changed, once:

- Nothing left behind: dead code, commented-out code, debugging output, stray files.
- Nothing duplicated: no second version of something that already existed.
- Each change sits where that kind of code lives, and reads like the code around it.
- If what goes where changed and the repository has an ARCHITECTURE.md, it says so.
- Your work is committed (unless you were told not to).
